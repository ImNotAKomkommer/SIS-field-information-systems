# AI English Tutor Desktop App

Desktop project for SIS Project requirements.

## Features

1. Authentication
- Register
- Login
- Logout

2. User profile
- Full name
- Email
- English level
- Learning goal
- Progress status

3. Tutor Search
- One English tutor
- Photo placeholder
- Full name
- Bio
- Phone number
- Write to tutor
- Book a lesson

4. English Lecture
- Locked before booking
- Unlocks after booking
- Present Simple lecture
- YouTube video button
- Completion button

5. Quiz
- Locked before completing the lecture
- 10 questions
- Automatic score calculation
- Result saved to profile

6. AI Assistant
- Prototype AI assistant
- Real AI with ChatGPT API
- Answers questions about Present Simple, booking, quiz and study plan

## New V2 features

- Tutor search by name
- Three tutors in the system
- One available tutor and two busy tutors
- Busy tutors cannot receive messages or bookings
- Separate tutor profile page
- Fixed tutor bio layout with proper text wrapping
- User can send a message and book a lesson with the available tutor
- The available tutor accepts the request
- Lecture unlocks after booking
- Same tutor cannot be booked twice
